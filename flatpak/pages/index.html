Mailophant

Read and archive your mail backups

Install on Linux

Install

This downloads a small installer file. Open it and GNOME Software or KDE Discover installs Mailophant. Updates then arrive like for any other app.

Needs Flatpak. If your distribution doesn't have it yet, see flathub.org/setup.

From the terminal

flatpak install --user @PAGES_URL@/mailophant.flatpakref
flatpak run io.github.developer_simon.mailophant

Updates come with flatpak update.

Beta

Pre-releases for testing new features. They can have rough edges, so keep a backup of your library. 

flatpak install --user @PAGES_URL@/mailophant-beta.flatpakref

Back to the stable version: flatpak make-current --user io.github.developer_simon.mailophant stable
